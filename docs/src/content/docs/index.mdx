SAI Guard Protocol evaluates a **user intent** and a **transaction proposal** before signing. The [SAI Guard Risk Engine](/reference/risk-engine/) returns `PROTECTED`, `WARNING`, or `BLOCKED`. The wallet remains the signing authority.

**AI Transaction Protect** is the SAI Wallet feature powered by this protocol.
