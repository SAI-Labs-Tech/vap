**SAI Guard Protocol** independently analyzes, simulates, and risk-checks a blockchain signing request against the user's stated intent. The user remains the signing authority.

<CardGrid>
	<Card title="Simulate before signature" icon="i-heroicons:beaker" bordered>
		Decode the payload and derive balance changes from simulation. Do not trust a dApp caption or an agent summary.
	</Card>
	<Card title="AI is not the oracle" icon="i-heroicons:shield-check" bordered>
		Independent AI checks whether simulated effects match intent. Deterministic policy produces PROTECTED, WARNING, or BLOCKED.
	</Card>
	<Card title="User signs" icon="i-heroicons:lock-closed" bordered>
		SAI Guard does not silently sign. Construction, verification, authorization, and execution are separate steps.
	</Card>
</CardGrid>
